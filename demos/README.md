# Demonstrations

Each demonstration is a folder holding only:

- a specification of the model;
- a list of edits applied to it;
- a data manifest saying where each series comes from;
- stored reference results from the original authors' code, with a note of where they came from.

A demonstration contains no Python. It is run by the one generic command that runs any specification. If a demonstration seems to need code of its own, a general building block is missing from mutatis; see the rules in [PLAN.md](../PLAN.md).
